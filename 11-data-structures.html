Tableaux

Nous avons déjà vu les tableaux en C, qui sont des structures de données permettant de stocker une séquence d'éléments de même type. Les tableaux sont des blocs contigus de mémoire qui peuvent être accédés par leur indice. 

int numbers[] = {1, 2, 3, 4, 5};

L'avantage de cette structure de données est l'accès rapide aux éléments par leur indice. Cependant, la taille d'un tableau est fixe et ne peut pas être modifiée dynamiquement.

De plus, les opérations d'insertion et de suppression d'éléments dans un tableau peuvent être coûteuses en termes de performances, car elles nécessitent de déplacer les éléments existants.

Queue (file)

Une file est une structure de données qui permet de stocker des éléments dans un ordre FIFO (First In, First Out). Les éléments sont ajoutés à la fin de la file et retirés du début de la file. 

const int MAX_SIZE = 100;

struct Queue {
    int items[MAX_SIZE];
    int size;
};

Les opérations de base sur une file sont enqueue (ajouter un élément) et dequeue (retirer un élément).

Visualisation d'une file

Stack (pile)

Une pile est une structure de données qui permet de stocker des éléments dans un ordre LIFO (Last In, First Out). Les éléments sont ajoutés et retirés du sommet de la pile. 

const int MAX_SIZE = 100;

struct Stack {
    int items[MAX_SIZE];
    int size;
};

Les opérations de base sur une pile sont push (ajouter un élément) et pop (retirer un élément).

Visualisation d'une pile

Tableaux - Avantages et inconvénients

Avantages

  • Accès rapide aux éléments par leur indice.
  • Utilisation efficace de la mémoire.
  • Facile à utiliser et à comprendre.

Inconvénients

  • Taille fixe.
  • Opérations coûteuses d'insertion et de suppression.
  • Peut entraîner un gaspillage de mémoire si la taille est trop grande.

Listes chaînées

Les listes chaînées sont des structures de données qui permettent de stocker une séquence d'éléments en utilisant des pointeurs. Chaque élément de la liste contient une valeur et un pointeur vers l'élément suivant. 

struct Node {
    int data;
    struct Node *next;
};

Vous pouvez parcourir une liste chaînée en utilisant des boucles et des pointeurs pour accéder à chaque élément. 

struct Node *head = NULL;
struct Node *current = NULL;

for (current = head; current != NULL; current = current->next) {
    printf("%d ", current->data);
}
Visualisation d'une liste chaînée

Exemple de liste chaînée

// node.h
struct Node {
    int data;
    struct Node *next;
};

void add_node(struct Node **head, int data);
void print_list(struct Node *head);
// node.c
#include <stdio.h>
#include <stdlib.h>
#include "node.h"

void add_node(struct Node **head, int data) {
    struct Node *new_node = (struct Node *)malloc(sizeof(struct Node));
    new_node->data = data;
    new_node->next = *head;
    *head = new_node;
}

void print_list(struct Node *head) {
    struct Node *current = head;
    while (current != NULL) {
        printf("%d ", current->data);
        current = current->next;
    }
    printf("\n");
}

Le paramètre head de la fonction add_node est un pointeur vers un pointeur de structure Node. Cela permet de modifier le pointeur de tête de la liste chaînée.

Double pointeur

Dans l'exemple précédent, le paramètre head de la fonction add_node est un double pointeur de structure Node. Cela permet de modifier le pointeur de tête de la liste chaînée.

Une autre approche consiste à renvoyer le nouveau pointeur de tête de la liste chaînée en tant que valeur de retour de la fonction. 

void add_node(struct Node **head, int data) {
    // Implementation
    *head = new_head;
}

add_node(&head, 1);
struct Node* add_node(struct Node *head, int data) {
    // Implementation
    return new_head;
}

head = add_node(head, 1);

Exemple de liste chaînée (suite)

// main.c
#include <stdio.h>
#include <stdlib.h>
#include "node.h"

int main() {
    struct Node *head = (struct Node *)malloc(sizeof(struct Node));
    head->data = 1;
    head->next = NULL;

    add_node(&head, 2);
    add_node(&head, 3);

    print_list(head); // Output: 3 2 1
    return 0;
}

Dans cet exemple, les nouveaux éléments sont ajoutés au début de la liste chaînée en modifiant le pointeur de tête.

On parle alors de LIFO (Last In, First Out ou pile) à l'inverse de FIFO (First In, First Out ou file) car les éléments sont retirés dans l'ordre inverse de leur insertion.

Liste chaînée - Améliorations

Les listes chaînées peuvent être améliorées en utilisant des listes doublement chaînées, où chaque nœud contient un pointeur vers le nœud précédent et le nœud suivant. Cela permet de parcourir la liste dans les deux sens.

Il est également possible d'utiliser des listes circulaires, où le dernier nœud pointe vers le premier nœud, formant ainsi un cycle. Cela permet de parcourir la liste de manière continue sans avoir à vérifier si le pointeur suivant est NULL.

Liste chaînée - Avantages et inconvénients

Avantages

  • Insertion et suppression rapides en début de liste.
  • Utilisation efficace de la mémoire.
  • La taille de la liste peut être modifiée dynamiquement.

Inconvénients

  • Accès lent aux éléments au milieu de la liste.
  • Nécessite plus de mémoire que les tableaux.
  • Complexité de mise en œuvre plus élevée.

Arbres binaires

Les arbres binaires sont des structures de données qui permettent de stocker des éléments de manière hiérarchique. Chaque élément de l'arbre est appelé un nœud et peut avoir jusqu'à deux nœuds enfants, appelés nœud gauche et nœud droit. 

struct Node {
    int data;
    struct Node *left;
    struct Node *right;
};
Visualisation d'un arbre binaire

Balanced / Unbalanced

Un arbre binaire équilibré est un arbre dans lequel la différence de hauteur entre les sous-arbres gauche et droit de chaque nœud est au maximum de 1. Cela garantit que l'arbre reste équilibré et que les opérations de recherche, d'insertion et de suppression restent efficaces.

Arbres binaires - Avantages et inconvénients

Avantages

  • Recherche rapide des éléments.
  • Insertion et suppression efficaces.
  • Utilisation efficace de la mémoire.

Inconvénients

  • Complexité de mise en œuvre plus élevée.
  • Les opérations de rotation peuvent être coûteuses.
  • Les arbres binaires peuvent devenir déséquilibrés.

Dictionnaires

Les dictionnaires sont des structures de données qui permettent de stocker des paires clé-valeur. Chaque élément du dictionnaire est associé à une clé unique qui permet d'accéder à sa valeur. 

struct Dictionary {
    char *key;
    int value;
};

Dictionnaires - Avantages et inconvénients

Avantages

  • Recherche rapide des éléments par clé.
  • Insertion et suppression efficaces.
  • Peut stocker des données de manière structurée.

Inconvénients

  • Les clés doivent être uniques.
  • Peut entraîner un gaspillage de mémoire si la taille est trop grande.
  • Complexité de mise en œuvre plus élevée.

Tables de hachage

Les tables de hachage sont des structures de données qui permettent de stocker des éléments en associant une clé à une valeur. Les tables de hachage utilisent une fonction de hachage pour calculer l'indice de stockage de chaque élément. 

struct HashTable {
    int size;
    struct Dictionary **table;
};

Tables de hachage - Avantages et inconvénients

Avantages

  • Recherche rapide des éléments par clé.
  • Insertion et suppression efficaces.
  • Peut stocker des données de manière structurée.

Inconvénients

  • Les clés doivent être uniques.
  • Peut entraîner un gaspillage de mémoire si la taille est trop grande.
  • Complexité de mise en œuvre plus élevée.
